# Customer Churn Analytics

An end-to-end Data Science project that predicts customer churn using XGBoost and visualizes business insights with an interactive Power BI dashboard.

## Overview

This project analyzes customer behavior, builds a machine learning model to predict churn, and presents key business KPIs through Power BI.

## Tech Stack

* Python
* Pandas & NumPy
* Scikit-learn
* XGBoost
* MySQL
* Power BI
* Jupyter Notebook

## Key Features

* Customer churn prediction using XGBoost
* Data preprocessing & feature engineering
* Interactive Power BI dashboard
* SQL database schema
* Business KPI analysis

## Dashboard KPIs

* Total Customers
* Churned Customers
* Churn Rate
* Average Monthly Fee
* Churn by Contract Type
* Churn by Payment Method
* Churn by Gender
* Churn by Country

## Machine Learning Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. Feature Engineering
4. Train/Test Split
5. XGBoost Model Training
6. Model Evaluation
7. Model Export (.pkl)
8. Power BI Visualization

## Dataset

* Records: 10,000 Customers
* Target Variable: `churn`
* Features: Demographics, Contract, Payment, Usage & Support
